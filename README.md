# Personal Portfolio Website

A personal portfolio website built with HTML and CSS to introduce the developer, list skills and projects, and provide contact information.

## Sections

- Home / introduction
- About
- Skills
- Projects
- Contact

## Built with

- HTML5
- CSS3

## Run locally

1. Clone or download this repository.
2. Open `main.html` in a web browser.

No build tools are required for the current static version.

## Before publishing

The HTML currently references `profile.jpg` and `resume.pdf`. Add those files to the expected location or update the paths. The contact section also contains example placeholder details; replace them with contact links you intend to publish.

Some project cards currently use `#` links. Replace these with the actual repository or project URLs before presenting the site as a finished portfolio.
